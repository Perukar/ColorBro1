# Color-logic safety — покажчики (джерело правди = закомічені тести + LOCKED docs)

**Важливо:** цей файл — **покажчики**, а не визначення. Точна логіка живе у **закомічених** тестах PERUKAR (`test_www_business_scenarios.js`, `test_www_mass_model.js`, `test_www_render_runtime.js`, `test_www_mapping.js`) та в `www/core.js`, а контракт верхнього рівня — в `AGENTS.md` / `docs/LOGIC_LOCKED` / `docs/AGENTS_LOCKED`. Не переписуй ці правила з пам'яті у код і не дублюй їх у двох місцях — інакше вони розійдуться, і скіл почне брехати.

## Застереження про брудні/змінені тести

**Не вважай змінені незакомічені тести авторитетними**, якщо вони послаблюють наявний контракт AGENTS.md або LOCKED-док. Клас прикладу:

```
BRAND-MISSING-* NO-APPROVED  не має тихо ставати
BRAND-GENERIC-* ADVISORY-APPROVED  без явного оновлення locked-rule.
```

Тобто: якщо брудний diff змінює тест так, що ворота безпеки слабшають, це **підозра**, а не нова правда. Рішення — за пріоритетом джерел правди (SKILL.md): AGENTS.md / LOCKED docs виграють у брудних тестів; конфлікт із закоміченими тестами → STOP.

## Safety-інваріанти (НЕ спрощувати)

- **target_direction** — обов'язковий; без нього розрахунок не валідний.
- **allergy / scalp safety gates** — обов'язкові ворота; не обходити й не послаблювати.
- **length / density / thickness** — обов'язкові поля; відсутність → `missingCriticalFields`, а не «дефолт».
- **Special Blond, base 6** — ручний режим (manual), не автоматизувати.
- **Grey + Special Blond** — ручний режим / заблоковано; без автоматичного рецепта.
- **diagnostic third zone** — не повинна протікати у production-рецепт (third-zone leak заборонено).
- **productionReady** — захищений прапор; не виставляти в обхід умов.

## Що робити при сумніві

Якщо незрозуміло, чи зміна безпечна для color-logic — **audit, не edit**. Виведи звіт зі STATUS: BLOCKED, перелічи інваріанти під ризиком і тести, що їх покривають, і чекай явного рішення. Будь-яка зміна, що зачіпає перелічене, — це LOCKED-class задача (явний дозвіл + оновлення відповідних тестів/доків).
