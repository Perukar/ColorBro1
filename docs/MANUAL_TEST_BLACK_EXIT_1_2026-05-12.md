# Manual test spec: BLACK-EXIT-1

## 1. ID сценарію

BLACK-EXIT-1

## 2. Назва

Вихід із чорного косметичного пігменту.

## 3. Мета

Перевірити, що система не формує точний фінальний рецепт для виходу з чорного косметичного пігменту без додаткової діагностики.

## 4. Вхідні дані

- Історія фарбування: чорний косметичний пігмент.
- Поточна база: затемнена косметична база.
- Бажаний результат: світліший або нейтральніший напрям після виходу з чорного.
- Стан полотна: потребує уточнення.
- Дані про нашарування: не задані або неповні.
- Дані про попередні змивки: не задані або неповні.
- Дані про фон освітлення: не задані або неповні.

## 5. Поточна поведінка / що треба перевірити

Перевірити, чи система не видає точний фінальний рецепт як безумовно готовий до виконання без уточнення:

- кількості нашарувань чорного пігменту;
- історії змивок або освітлення;
- фактичного фону після діагностики;
- пористості та міцності полотна;
- ризику нерівномірного виходу з чорного.

## 6. Очікувана безпечна поведінка

Система має повернути `MANUAL_REQUIRED` або окремий блок діагностики перед будь-яким фінальним рецептом.

Фінальний рецепт не має виглядати як безумовно затверджений без ручного рішення майстра.

## 7. Рівень ризику

HIGH.

## 8. Що перевіряє сценарій

- Виявлення історії чорного косметичного пігменту.
- Заборону точного фінального рецепта без діагностики.
- Наявність ручного рішення або діагностичного блоку.
- Відсутність безумовного `APPROVED` для високоризикового виходу з чорного.

## 9. Поточний статус

Manual test spec створено, автоматичний тест ще не реалізовано, бізнес-логіка ще не змінювалась.

## 10. Наступний крок

Підготувати автоматичний діагностичний тест, який фіксує поточну поведінку для `BLACK-EXIT-1` без зміни бізнес-логіки.
