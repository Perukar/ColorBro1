# Manual test spec: ZONES-ROOT-LENGTH-ENDS

## 1. ID сценарію

ZONES-ROOT-LENGTH-ENDS

## 2. Назва

Різні рівні на корені, довжині та кінцях.

## 3. Мета

Перевірити, що система не пропонує одну суміш на всі зони, якщо корінь, довжина та кінці мають різні вихідні рівні.

## 4. Вхідні дані

- Корінь: один рівень глибини тону.
- Довжина: інший рівень глибини тону.
- Кінці: окремий рівень або окремий стан полотна.
- Бажаний результат: один загальний цільовий напрям.
- Сивина: за потреби 0% або окремо задане значення.
- Історія фарбування: без критичних протипоказань, якщо задача перевіряє саме різницю зон.

## 5. Поточна поведінка / що треба перевірити

Перевірити, чи система:

- розпізнає різницю між коренем, довжиною та кінцями;
- не формує одну універсальну суміш для всіх зон без попередження;
- не показує зональний випадок як простий однорідний рецепт;
- не втрачає ризик нерівномірного результату.

## 6. Очікувана безпечна поведінка

Система має або сформувати окремі рекомендації для зон, або вимагати ручне рішення майстра.

Якщо окремі зони ще не підтримані, очікувана безпечна поведінка: `MANUAL_REQUIRED` або чітке попередження, що одна суміш не може бути підтверджена як безпечна.

## 7. Рівень ризику

HIGH.

## 8. Що перевіряє сценарій

- Обробку різних вихідних рівнів у зонах.
- Запобігання одній суміші для неоднорідного полотна.
- Наявність manual decision для зонального випадку.
- Відсутність безумовного `APPROVED`, якщо зональна логіка недостатня.

## 9. Поточний статус

Manual test spec створено, автоматичний тест ще не реалізовано, бізнес-логіка ще не змінювалась.

## 10. Наступний крок

Підготувати автоматичний діагностичний тест для сценарію `ZONES-ROOT-LENGTH-ENDS`, який перевіряє, чи не видається одна фінальна суміш без попередження.
