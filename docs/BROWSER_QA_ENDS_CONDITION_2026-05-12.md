# Browser QA ends_condition

Дата: 2026-05-12

## 1. Як запущено

- Browser QA виконано через headless Chrome.
- URL: `http://127.0.0.1:8081/www/index.html`.
- Локальний сервер: `python -m http.server 8081`.
- Після тестування сервер було зупинено.
- Файли проєкту під час тестування не змінювались.

## 2. Перевірене поле

Поле `ends_condition`:

- label: `Стан кінців`;
- варіанти:
  - `Не вказано`;
  - `Здорові`;
  - `Пористі`;
  - `Ламкі`;
  - `Сильно пошкоджені`;
  - `Критично пошкоджені`.

Результат: PASS.

## 3. Перевірені сценарії

| Сценарій | Статус | Фактична поведінка |
| --- | --- | --- |
| APPROVED 8/8/8 + здорові | PASS | результат рендериться, status `APPROVED`, warning про кінці немає |
| Пористі кінці + освітлення 6→9 | PASS | `MANUAL_REQUIRED`, manual “Стан кінців”, warning про ризиковий стан кінців |
| Ламкі кінці + високий підйом 6→9 | PASS | `MANUAL_REQUIRED`, manual “Стан кінців”, warning про ризиковий стан кінців |
| Критично пошкоджені кінці 6→7 | PASS | `MANUAL_REQUIRED`, warning про пошкоджені кінці, окремий рецепт кінців не рахується |
| ends_level різний, ends_condition не вказано | PASS | `MANUAL_REQUIRED`, manual “Окрема оцінка кінців”, warning про відсутній стан кінців |

## 4. Фактичні warning/status

- `APPROVED | ЦІЛЬ: 8.0` для базового сценарію.
- `MANUAL_REQUIRED` для ризикових ends-сценаріїв.
- `⚠️ РИЗИКОВИЙ СТАН КІНЦІВ: ends_condition вказує на пористі, ламкі або пошкоджені кінці...`
- `⚠️ НЕДОСТАТНЬО ОЦІНКИ КІНЦІВ: ends_level відрізняється..., але ends_condition не вказано...`

## 5. Console errors

- Критичних JS/runtime errors не виявлено.
- `favicon.ico 404` не є критичною помилкою застосунку.

## 6. Висновок

Browser QA для `ends_condition` пройдено.
UI відповідає очікуваній guard-логіці.
Поле `ends_condition` не зламало базовий `APPROVED`-сценарій.
Ризикові стани кінців переводять результат у `MANUAL_REQUIRED`.

## 7. Обмеження

- Це browser/headless QA, не фізичний планшетний QA.
- Окремий `endsRec` не реалізований.
- Окрема історія кінців / base_type кінців ще не реалізовані.
- Окрема формула і mass model для кінців не реалізовані.
