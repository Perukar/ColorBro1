# QA Smoke Test — ПЕРУКАР

Дата: 2026-05-12

## Що перевірено

- відкриття `index.html`;
- консоль браузера;
- робота кнопок;
- збереження введених даних;
- сценарій APPROVED;
- сценарій BLOCKED.

## Що пройшло

- `index.html` завантажується;
- консоль без помилок;
- кнопки активні;
- дані форми зберігаються;
- базовий APPROVED-сценарій проходить;
- BLOCKED-сценарій для небезпечної комбінації спрацьовує.

## Що не доведено

- правильність усіх формул;
- правильність вибору типу барвника;
- повна готовність до експлуатації;
- коректність логіки Special Blond;
- повна мовна уніфікація.

## Виявлені баги

- сценарій 6 → 8.3 пропонує Special Blond, що потребує окремої колористичної перевірки;
- при неповних даних деякі поля результату можуть показувати 0 або залишатися порожніми.

## UX-зауваження

- мовна мішанина UA/RU;
- після генерації результату бажаний автоскрол або фокус на протокол.

## Колористичні ризики

- Special Blond для бази 6 може бути некоректним без брендового правила;
- smoke test не підтверджує професійну правильність рецепта.

## Вердикт

Базовий UI Smoke Test пройдено. Колористична логіка потребує окремої перевірки.

## Наступні дії

- діагностувати логіку Special Blond для сценарію 6 → 8.3;
- уніфікувати мову інтерфейсу;
- покращити відображення результату при неповних даних;
- додати або перевірити автоскрол до результату.
