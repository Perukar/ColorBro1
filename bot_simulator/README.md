# ПЕРУКАР bot simulator

Це локальний no-server HTML-симулятор кнопкового бота для перевірки алгоритму ПЕРУКАР.

Це не Telegram-бот, не серверний бот і не production-інтеграція. Файл відкривається напряму у браузері й працює без npm, CDN або зовнішніх бібліотек.

## Як відкрити

1. Відкрийте файл `bot_simulator/index.html` у браузері.
2. Натискайте кнопки сценарію крок за кроком.
3. Наприкінці симулятор покаже сухий фінальний протокол зі статусом, ризиками, забороненими діями і рекомендованою наступною дією.

Якщо браузер не дозволить завантажити `bot_flow.json` через `file://`, симулятор використає вбудований fallback flow з `bot_simulator.js`.

## Для чого це потрібно

Симулятор потрібен для перевірки кнопкового алгоритму ПЕРУКАР перед складнішими інтеграціями. Він показує, як система збирає параметри через кнопки та як базова MVP-логіка переводить сценарій у `OK`, `NEED_REVIEW` або `BLOCKED`.

## Обмеження

- Немає AI-діалогу.
- Немає сервера.
- Немає Telegram API.
- Немає збереження даних між відкриттями сторінки.
- Немає підключення до runtime-логіки ПЕРУКАР у `www/`.
- Немає повної перевірки рецепта, бренду, окисника або пропорції.

## Поточна логіка ризиків

MVP-логіка перевіряє тільки базові ризики: хна/метали, невідома історія на ненатуральній довжині, сивина 50%+ з холодним напрямом, пошкоджена або плямиста довжина, підйом на 2+ рівні та підйом по пошкодженій довжині.

Цю логіку потрібно розширювати тільки після перевірки майстром і окремого погодження бізнес-правил.
